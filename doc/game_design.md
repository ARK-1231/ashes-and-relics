# 灰の王国と記憶の遺物 ゲーム設計書

## 1. 概要

本作は、滅びた王国の遺跡を探索する見下ろし型2DアクションRPGである。
プレイヤーは記憶を失った探索者となり、遺物と碑文を集め、仲間のミラとともに王国の守護者を倒して遺跡から脱出する。

現在の実装は、1回のプレイで探索・強化・ボス戦・エンディング分岐までを体験できる最小プロトタイプである。

## 2. 実装方式

- 言語: Python
- 描画・入力・ウィンドウ: Tkinter
- 表現: 見下ろし型2D
- 画面サイズ: 1280×720（最小900×560、リサイズ対応）
- ワールドサイズ: 2880×2880
- ゲームループ: 約60 FPS
- 外部ゲームライブラリ: 不使用

主要ファイルは以下のとおり。

- `src/dark_ruins_rpg.py`: ゲーム進行、入力、戦闘、描画
- `src/game_models.py`: 定数とデータモデル
- `src/boss_attacks.py`: ボスの弾幕生成
- `src/ally_navigation.py`: 仲間のA*経路探索

## 3. ゲームの目的と進行

1. タイトル画面からゲームを開始する。
2. ランダム配置された遺物と仲間のミラを探す。
3. 「灯火の小瓶」を入手してボス部屋の封印を解く。
4. 王国の守護者を倒す。
5. 遺物、仲間、真相度を引き継いで新しく生成された次の遺跡へ進む。

ステージの壁、通常敵、遺物、ミラの初期位置はシードを使って生成される。開始地点、祠、ボス部屋、ボス、碑文、出口は固定位置に配置される。生成後は開始地点から遺物・仲間・ボス部屋前まで到達可能かを検証する。

## 4. 操作

| 操作 | キー／入力 |
|---|---|
| 移動 | `WASD` / 矢印キー |
| 向きの指定 | マウス移動 |
| 近接攻撃 | 左クリック / `F` / `Enter` |
| 回避 | `Space` |
| 調べる | `E` |
| 灰刃へ切り替え | `1` |
| 灯火へ切り替え | `2` |
| 黒心へ切り替え | `3` |
| 聖杯へ切り替え | `4` |
| 籠手へ切り替え | `5` |
| 翼章へ切り替え | `6` |
| 暁火へ切り替え | `7` |
| 護符へ切り替え | `8` |
| 月雫へ切り替え | `9` |
| ポーズ | `P` / `Esc` |

タイトル画面とポーズ画面は、キーボードまたはマウスで操作できる。ゲームオーバー／クリア後は、`R`で同じステージへ1回だけ再挑戦でき、`N`で新しいステージを生成できる。

## 5. プレイヤー

### 基本性能

- 最大HP: 100
- 基礎攻撃力: 18
- 移動速度: 260
- 攻撃間隔: 0.65秒
- 攻撃範囲: 前方約120度、距離110＋敵半径以内

攻撃は範囲内で最も近い敵1体に命中する。壁越しには攻撃できない。命中時にはノックバック、ヒットストップ、画面揺れ、効果音、パーティクルが発生する。

### 回避

- 回避速度: 600
- 持続時間: 0.26秒
- 再使用時間: 10秒
- 回避中は敵の攻撃に対して無敵

### 回復と敗北

開始地点付近の壊れた祠で`E`を押すとHPが全回復する。HPが0になるとゲームオーバーになる。

## 6. 遺物と真相度

遺物は近づくと自動で入手する。入手した遺物は数字キーで切り替えられる。

### 灰刃の欠片

- 入手時に基礎攻撃力が18から30へ上昇
- 装備中は攻撃ダメージがさらに10上昇
- 真相度: 1

### 灯火の小瓶

- 入手するとボス部屋の封印扉が開く
- 装備中は「さまよう影」とボスへの攻撃ダメージが8上昇
- 装備中、プレイヤーが受けるダメージを4軽減する
- ミラの支援弾ダメージが8から14へ上昇
- ボス部屋付近の隠された碑文を読める
- 真相度: 1

### 黒い心臓石

- 入手時に自動で装備される
- 装備中は攻撃ダメージが18上昇
- 攻撃を当てるたびにHPを3回復
- 真相度: 2

### 第2遺跡から出現する聖遺物

- 命脈の聖杯: 最大HPを30上昇し、増加分を回復する
- 巨人の籠手: 攻撃力を16上昇する
- 白銀の翼章: 受けるダメージを5軽減する
- 聖杯を選択中は、攻撃命中時にHPを5回復する
- 籠手を選択中は、攻撃ダメージが22上昇する
- 翼章を選択中は、受けるダメージをさらに7軽減する
- 各聖遺物の真相度: 1

### 第3遺跡から出現する聖遺物

- 暁火の結晶: 攻撃力を24上昇する
- 古王の護符: 受けるダメージを8軽減する
- 月雫の宝珠: 最大HPを50上昇し、増加分を回復する
- 暁火を選択中は、攻撃ダメージが30上昇する
- 護符を選択中は、受けるダメージをさらに10軽減する
- 月雫を選択中は、攻撃命中時にHPを8回復する
- 各聖遺物の真相度: 1

隠された碑文の発見とミラの加入でも、それぞれ真相度が1上昇する。獲得可能な真相度の合計は6である。

## 7. 仲間: ミラ

ミラに近づくと自動で仲間になり、以後プレイヤーを追従する。壁で直進できない場合はA*経路探索を使って迂回する。

- 250以内にいる、射線が通った最寄りの敵へ自動で支援弾を撃つ
- 通常の支援弾ダメージは8、灯火装備中は14
- 支援攻撃の間隔は2秒
- プレイヤーHPが55%以下になると14回復する
- 回復の再使用時間は4秒
- ミラ同行中、プレイヤーが受けるダメージを5軽減する

### 後続の遺跡で出現する仲間

- 第2遺跡: 灰騎士レオン。加入すると受けるダメージをさらに3軽減する
- 第3遺跡: 星詠みノア
- 加入済みの仲間は仲間一覧として次の遺跡へ引き継がれる
- 新しい仲間が加入しても既存の仲間は消えず、全員が隊列として表示される
- 各仲間は独立した座標、追従目標、経路、行動クールタイムを持つ
- ミラはHP低下時の回復を優先し、それ以外は中距離支援弾で攻撃する
- 灰騎士レオンは短い間隔で近距離の敵を攻撃する
- 星詠みノアは長い射程から高威力の支援弾を放つ

## 8. 通常敵

各ステージには合計17体の通常敵が生成される。

| 敵 | 数 | HP | 攻撃力 | 移動速度 | 特徴 |
|---|---:|---:|---:|---:|---|
| 灰の兵士 | 8 | 45 | 10 | 95 | 標準的な近接敵 |
| 廃騎士 | 4 | 70 | 16 | 78 | 高耐久・高威力の近接敵 |
| さまよう影 | 5 | 32 | 14 | 125 | 素早い遠距離敵 |

敵の攻撃には予備動作があり、近接攻撃または弾を受けるとプレイヤーはダメージとノックバックを受ける。被弾後には0.55秒の無敵時間がある。

## 9. ボス: 王国の守護者

ボスは封印扉の先に配置され、扉が開くまで行動しない。
プレイヤーがボス部屋へ完全に入ると入口が「戦闘封鎖」状態になり、守護者を倒すまで外へ戻れない。同行中の仲間も封鎖時にボス部屋内へ集合する。

### 基本性能

- 最大HP: 240
- 最大シールド: 180
- 攻撃力: 22
- 第一形態の移動速度: 68

プレイヤーの攻撃はシールドを先に減らし、余ったダメージだけがHPに入る。

### 第二形態

第一形態でHPが120以下になると第二形態へ移行する。

- HPを240まで全回復
- シールドを180まで全回復
- 移動速度が88へ上昇
- 攻撃の予備動作と再使用時間が短縮
- 第二形態専用の螺旋弾と波状弾が追加

### 弾幕パターン

- 扇状弾: プレイヤー方向へ広がる弾幕
- 全方位弾: ボスを中心とする円形弾幕
- 槍状弾: 速度の異なる弾を狭い角度へ発射
- 螺旋弾（第二形態）: 回転する18発の円形弾幕を0.22秒間隔で4回連続発射
- 波状弾（第二形態）: 回避用の隙間を持つ横一列の弾幕

同じ弾幕パターンは連続で選ばれない。

### 階層別の攻撃構成

| 階層スタイル | 第一形態 | 第二形態 |
|---|---|---|
| 第1・第4・第7…遺跡 | 扇状弾、全方位弾、槍状弾 | 扇状弾、槍状弾、螺旋弾、波状弾 |
| 第2・第5・第8…遺跡 | 槍状弾、波状弾 | 槍状弾、波状弾、螺旋弾、扇状弾 |
| 第3・第6・第9…遺跡 | 全方位弾、螺旋弾 | 全方位弾、螺旋弾、波状弾、槍状弾 |

第4階層以降は上記3種類の攻撃スタイルを順番に繰り返す。形態移行時のHP・シールド回復や攻撃速度上昇は、すべての階層で共通である。

## 10. 画面表示と演出

- プレイヤーのHP、攻撃力、選択中の遺物、真相度を表示
- 目的地と回避の再使用状況を表示
- ミニマップに壁、封印扉、遺物、仲間、敵を表示
- 敵のHPを表示し、シールドを持つ敵にはシールドゲージも表示
- 敵の攻撃前に点滅、射線、円形範囲などの予告を表示
- 攻撃、被弾、回復、遺物取得、第二形態移行、撃破時に視覚・音響演出を表示

タイトル画面、操作説明画面、ポーズメニューを実装している。

## 11. ダンジョンの継続

第1・第2遺跡の守護者を倒すと、1秒間の撃破演出後に新しいシードで次の遺跡を生成する。第3遺跡の守護者を倒すとゲームクリアとなり、真相度に応じたエンディングを表示する。

- 取得済みの遺物と選択中の遺物を引き継ぐ
- ミラが加入済みなら、次の遺跡でも開始地点から同行する
- 攻撃力と真相度を引き継ぐ
- HPは最大まで回復する
- 未取得の遺物は次の遺跡に再配置され、引き続き入手できる
- 第2・第3遺跡では、その階層固有の新しい聖遺物と仲間が追加配置される
- 階層が1つ進むごとに、通常敵のHPは45%、攻撃力は25%、移動速度は7%ずつ上昇する
- 階層が1つ進むごとに、ボスのHPは55%、シールドは45%、攻撃力は28%、移動速度は7%ずつ上昇する
- 灯火の小瓶を取得済みなら、新しい遺跡の封印扉は開始時から開く
- 階層番号を1つ増やして画面に表示する

## 12. 現在の完成範囲

- ランダム生成される廃墟ステージ1つ
- プレイヤー1人
- 仲間1人（ミラ）
- 遺物9種（階層進行で順次追加）
- 通常敵3種、合計17体
- シールドと二形態を持つボス1体
- 通常敵の近接・遠距離攻撃
- ボスの5種類の弾幕
- 封印扉、回復の祠、隠された碑文、出口
- ボス撃破後の進行状況を引き継いだ連続ダンジョン生成
- 第2・第3遺跡固有の聖遺物と仲間
- タイトル、操作説明、ポーズ、再挑戦、新規ステージ生成
