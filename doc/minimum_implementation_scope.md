# 最小実装スコープ

## 1. 目的

本ドキュメントは、探索重視ダーク幻想RPGを最小限構成で実装する場合に、どこまで作るかを定義する。

最初から完成版の全要素を作るのではなく、「ゲームとして一周できる縦切り版」を目標にする。
探索、戦闘、遺物、仲間、真相分岐が最低限つながっている状態を作り、このRPGの核が面白いかを検証する。

## 2. 最小実装の範囲

### 作るもの

- 1つの廃墟マップ
- 主人公1人
- 仲間1人
- 遺物3種
- 敵2種
- ボス1体
- 簡易拠点メニュー
- エンディング2種
- 肩越し三人称カメラ
- リアルタイム移動
- 通常攻撃
- 回避
- 遺物による能力変化
- 真相ゲージによる結末分岐

### 今回は作らないもの

- 複数の王国マップ
- 仲間入替制の完全実装
- 仲間2人以上の同時運用
- 遺物5種以上
- 敵3種以上
- エンディング3種
- 本格的な町や拠点探索
- 複雑な会話分岐
- 装備画面の詳細UI
- セーブ・ロード
- クエスト管理システム

## 3. 縦切り版 v0.1 の流れ

1. プレイヤーが廃墟マップで開始する
2. 廃墟を探索する
3. 敵を倒しながら奥へ進む
4. 遺物を3つ集める
5. 遺物の力で封印扉を1つ開ける
6. 仲間を1人加入させる
7. ボスと戦う
8. ボスを倒す
9. 集めた真相量によって通常エンドか真相エンドに分岐する

## 4. 最小版で検証したいこと

- 廃墟を歩き回る探索が楽しいか
- 敵と戦う操作感が成立しているか
- 遺物を拾うことで探索や戦闘が変わるか
- 仲間がいることで戦い方か探索が変わるか
- 真相ゲージによって、もっと探索したいと思えるか
- ボス撃破までの流れが短編ゲームとして成立しているか

## 5. 成功条件

縦切り版 v0.1 は、以下を満たせば成功とする。

- プレイヤーが開始からエンディングまで一周できる
- 少なくとも1つの遺物が探索に影響する
- 少なくとも1つの遺物が戦闘に影響する
- 仲間が加入し、戦闘または探索に影響する
- ボス撃破後にエンディングが表示される
- 真相ゲージの値によってエンディングが2種類に分岐する

## 6. 実装優先度

### 最優先

- プレイヤー移動
- 肩越し三人称カメラ
- 1つの廃墟マップ
- 敵とのリアルタイム戦闘
- 遺物取得
- ボス戦
- エンディング表示

### 次に必要

- 仲間加入
- 遺物による能力変化
- 封印扉
- 真相ゲージ
- 簡易拠点メニュー

### 後回し

- 複数マップ
- 詳細な育成要素
- 複雑なUI
- 複数仲間の入替
- 多数の敵やボス
- セーブ・ロード
