# Dungeon environment textures

The game uses `floor_tile.png` (96 x 96) and `wall_tile.png` (32 x 32). Both were
generated with the built-in image generation tool and reduced to runtime sizes with
high-quality bicubic filtering. Full generated sources are stored in
`assets/sprites/archive/superseded_assets_2026-08-29.zip`.

## Final prompts

Floor: seamless orthographic ancient ruined-stone floor; crisp restrained pixel
art; broad irregular slabs, subtle cracks and sparse ash; flat ambient light;
medium blue-gray palette lighter than the characters; no objects, text, border,
deep blacks, or high-frequency noise.

Wall: seamless orthographic ruined masonry; crisp restrained pixel art; stacked
weathered blocks, chipped corners, shallow cracks and subtle mortar; cool slate
gray with violet-blue shadows; even ambient light; no objects, text, border,
perspective, pure black, or high-frequency noise.
