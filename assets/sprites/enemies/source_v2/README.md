# Ruined-knight upward attack source

The archived `ruined_knight_up_attack_sheet.png` was produced with the built-in
image generation tool, using the intact v5 upward attack frame as the identity/style
reference. The checker backdrop returned by generation was removed during
deterministic frame extraction; each pose was normalized into a 96 x 96 transparent
runtime frame. The full sheet now lives in
`assets/sprites/archive/superseded_assets_2026-08-29.zip`.
