# 味方キャラクター画像

組み込み画像生成ツールで生成した透過PNGを、ゲーム用の96×96ピクセルに分割・縮小しています。

- `mira.png`: ミラ。緑のフードと金色の杖を持つ回復役。
- `leon.png`: 灰騎士レオン。銀灰色の鎧と剣・盾を持つ騎士。
- `noa.png`: 星詠みノア。紫の衣装と星の杖を持つ魔法使い。
- `source_v1.png`: 生成した元の透過アトラス。

生成プロンプトの仕様: 見下ろし型ダーク幻想RPG用の3頭身ピクセルアート。左からミラ、レオン、ノアを等幅の3枠に配置し、正面向き・全身・透明背景・文字なしで描く。ミラは茶髪の三つ編み、緑のフード、クリーム色のローブと金の杖。レオンは銀灰色の鎧、剣と盾。ノアは銀髪、紫と紺のローブ、星の杖。

`src/dark_ruins_rpg.py` が起動時に読み込み、合流前と同行中の両方に表示します。足元を揃え、名前・支援攻撃ゲージは頭上に表示します。読み込みに失敗した場合は静止画像、さらに既存の図形表示に戻ります。

## 動作画像 v2

- `source_v2.png`: 組み込みimagegenツールで生成した6列×6行の透過アトラス。元の3人の見た目を参照して作成。
- `frames_v2/`: 96×96の透過PNG、各15枚・合計45枚。各方向の待機1枚・歩行2枚、攻撃2枚、支援1枚。右向きは左向きを反転。
- 移動した距離から歩行と方向を判定し、停止時は待機に戻ります。攻撃ポーズは0.45秒表示、ミラの回復時は回復専用画像を表示します。レオンとノアの支援画像は素材として収録し、現在のゲーム行動では使いません。
