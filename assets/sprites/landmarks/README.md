# Landmark sprites

Generated using the built-in image_gen tool. Runtime: 128 x 128 RGBA PNG, ground anchor (64, 120), draw with anchor=s at world y+8. Images are loaded once at startup. Keep source/ originals for future resizing. Rebuild with tools/prepare_landmark_sprites.ps1. Shrine appears at the healing point; stairs on floors 1–2; exit on floor 3. Existing interaction rules are preserved.
