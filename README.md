# 灰の王国と記憶の遺物

Python標準のTkinterで動く、見下ろし型2Dダーク幻想RPGです。遺跡を探索して遺物と仲間を集め、ボス「王国の守護者」を倒します。外部ゲームライブラリは不要です。

## 起動方法

コマンドは、このREADMEがあるプロジェクトのフォルダーで実行してください。

Python 3.10以降とTcl/Tkが必要です。Tkinterを含むPython環境で実行してください。

```powershell
python .\src\dark_ruins_rpg.py
```

追加パッケージのインストールは不要です。`requirements.txt`にも外部依存はありません。効果音はWindowsの`winsound`を使用し、対応しない環境では無音になります。

VS Codeでは、`Ctrl + Shift + P` → `Python: Select Interpreter`から、Tkinterを利用できるPythonを選択してください。

## ゲームの流れ

1. タイトル画面で「ゲーム開始」を選び、ランダム生成された遺跡を探索します。
2. 遺物に近づくと自動で入手できます。「灯火の小瓶」で封印扉を開きます。
3. 仲間と合流し、祠での回復や隠し碑文の調査をしながらボスへ進みます。ボス戦中は部屋の入口が封鎖されます。
4. 第1・第2遺跡のボスを倒すと、約1秒後に進行状況を引き継いで次の遺跡へ進みます。第3遺跡のボスを倒すとクリアです。

遺物・仲間・碑文で集めた真相度によって、通常エンド・断片エンド・真相エンドに分岐します。

## ステージイベント

階層が進むと通常敵と召喚される援軍が強化されます。第1遺跡を基準に、第2遺跡はHP1.7倍・攻撃力1.4倍・速度1.1倍、第3遺跡はHP2.4倍・攻撃力1.8倍・速度1.2倍です。ボスの基本HP／攻撃力／シールドは、第1遺跡が240／22／180、第2遺跡が480／34／306、第3遺跡が720／46／432となります。ステージイベントの補正はさらに適用されます。

ステージ生成時にイベントが1つ抽選されます。次の階層へ進むたびに、それまでの効果を引き継いだまま、重複しないイベントが1つ追加されます。第3遺跡では最大3種類が同時に発生します。追加抽選では「静穏」は選ばれません。発生中のイベントは画面上部にすべて表示されます。

| イベント | 効果 |
| --- | --- |
| 静穏 | 特別な変化なし |
| 濃霧 | プレイヤー周辺以外を完全に遮蔽。ミニマップの地形・敵・遺物も確認不能 |
| 堅牢な群れ | 通常敵とボスのHPが35%増加。ボスのシールドも35%増加 |
| 凶暴化 | 通常敵とボスの攻撃力が30%増加 |
| 影走り | 通常敵とボスの移動速度が25%増加 |
| 群体発生 | 通常敵が10体増加 |
| 双王の影 | 低確率で発生。守護者が2体出現し、両方の撃破が必要 |
| 不死者の契約 | 通常敵が倒されてから3秒後、HP50%で一度だけ復活 |
| 血の代償 | プレイヤーの攻撃力が25%上昇。攻撃ごとにHPを2消費（HP1で停止） |
| 守護者の号令 | ボス戦中、9秒ごとに守護者1体につき灰の兵士1体を召喚。同時召喚数は最大10体 |

複数イベントの効果は同時に適用されます。ただし極端な組み合わせでは補正が入り、「堅牢な群れ＋凶暴化」はHP25%・攻撃力20%増加、「濃霧＋影走り」は速度15%増加、「不死者の契約＋群体発生」はHP35%で復活します。「双王の影＋守護者の号令」では召喚間隔が12秒、同時召喚数が6体となり、2体の守護者が交互に援軍を呼びます。同じ生成配置へ再挑戦した場合、イベントも同じ内容になります。

新しい階層では追加イベントの名前と効果が中央に4秒間表示されます。不死者の復活地点には残り時間付きの緑色マーカー、守護者の召喚前には2秒間の橙色予告リングが表示されます。

## 操作

### 武器と設定（追加）

- `Q`で剣 → 槍 → 大斧を切り替えます。攻撃の待ち時間中は変更できません。
- 剣は標準、槍は長射程・狭い範囲、大斧は広範囲・高威力で攻撃間隔が長めです。遺物スキルと併用できます。
- タイトル・プレイ中・ポーズ中に`F2`で設定を開きます。設定中はゲームが停止します。
- 難易度は被ダメージ倍率（やさしい65%、標準100%、難しい140%）、効果音は0～100%、画面揺れはオン／オフです。
- 攻撃・回避・調べる・武器切替のキーを変更できます。欄を選択して割り当てたいキーを押し、「適用して戻る」で反映します。左クリックとEnterでの攻撃も利用できます。
- 設定は起動中に保持されます。終了すると初期設定に戻ります。
- 仲間は壁を避けつつ、見通せる経路の途中地点を飛ばして滑らかに追従します。
- ボスは近接攻撃範囲、弾の初期発射方向、発動までの秒数を予告します。螺旋弾は発射後に旋回するため、予告線は初期方向を示します。

| キー・マウス | 操作 |
| --- | --- |
| `WASD` / 矢印キー | 移動 |
| マウス移動 | 攻撃方向を指定 |
| 左クリック | マウス方向へ攻撃 |
| `F` / `Enter` | カーソル方向へ攻撃（長押しで繰り返す） |
| `Space` | カーソル方向へ回避。約0.26秒間無敵、再使用まで10秒 |
| `E` | 近くの祠で回復／碑文を調べる |
| `1`～`9` | 入手済みの遺物スキルへ切り替え |
| `P` / `Esc` | ポーズ |
| `R` | ゲームオーバー／クリア後、同じ生成配置で再挑戦。再挑戦は1回まで |
| `N` | ゲームオーバー／クリア後、新しい冒険を開始 |

メニューでは`↑↓` / `W S`で選択、`Enter` / `Space`で決定します。マウスでも選択できます。

## 仲間と敵

### 追加された敵と探索記録

- 灰の突撃兵：橙色の進路予告後に直線突撃します。横へ回避でき、壁に当たると止まります。
- 灰の祈祷師：5秒間隔で、壁に遮られていない近くの通常敵1体をHP15回復します。ボスや死亡した敵は回復しません。
- 盾の廃騎士：水色の弧が示す正面からのプレイヤー攻撃を65%軽減します。旋回が遅いため、側面や背後へ回り込むと通常のダメージを与えられます。
- 追加の敵には突撃兵・祈祷師・盾騎士それぞれの透過スプライトがあります。4方向の待機・歩行・攻撃を表示し、画像が欠けた敵だけ色付きの代替表示になります。通常敵の総数は従来と同じです。
- ミニマップの黒い部分は未探索です。発見した地形・祠・階段／出口・未回収の遺物は、その遺跡にいる間記録されます。階層移動・再挑戦・新しい冒険で探索記録はリセットされます。
- 敵マーカーは現在見える範囲だけ表示されます。「濃霧」イベント中は従来どおり地図全体を確認できません。

- 仲間は第1遺跡のミラ、第2遺跡の灰騎士レオン、第3遺跡の星詠みノアの3人です。自動で追従・支援攻撃を行い、ミラは主人公のHP低下時に回復も行います。
- 仲間は240px以内で壁に遮られていないとき、初期耐久値20、仲間が1人増えるごとに5増加するシールド（1人で20、2人で25、3人で30）を自動付与します。HUDのゲージ上限も人数に連動します。加入時に残っているシールドはそのままで、次回付与から増加した耐久値になります。シールドが割れた時点から全員共通で12秒待って再付与できるようになります。初回付与には待ち時間がなく、重ねがけはせず、ミラの回復を優先します。シールドは防御計算後のダメージをHPより先に吸収し、残量をHUDと水色のバリアで表示します。階層移動・再挑戦時にはリセットされます。
- 通常敵は灰の兵士・廃騎士・さまよう影・灰の突撃兵・灰の祈祷師・盾の廃騎士の6種類です。
- ボス「王国の守護者」は遺跡ごとに強さと技が変わります。HPが半分以下になると第二形態へ移行し、HPとシールドが全回復します。

### ボスの攻撃と画像

| 攻撃 | ポーズ・色 |
| --- | --- |
| 近接斬撃 | 大剣を振る赤い斬撃 |
| 扇状弾 | 紫の魔法弾を放つ構え |
| 全周弾 | 桃色の魔法の輪を展開 |
| 魔槍 | 水色の魔槍を突き出す構え |
| 螺旋弾 | オレンジ色の螺旋をまとった構え |
| 衝撃波 | 剣を地面へ打ち込む金色の衝撃 |

溜め中と発動直後に対応する画像へ切り替わります。攻撃画像は各技1枚、歩行は正面向きの4コマアニメーションです。移動中だけ歩行コマを進め、停止時は待機、攻撃時は攻撃ポーズを優先します。

ボスの技は階層が上がるごとに増え、前の階層で使った技も引き継ぎます。近接斬撃は全階層・両形態で使用します。

ボスのHPは階層ごとに180、基本攻撃力は9ずつ増加します。遠距離攻撃のダメージも、この基本攻撃力をもとに技ごとの補正を適用して増加します。

| 階層 | 最大HP | 基本攻撃力 |
| --- | --- | --- |
| 第1遺跡 | 240 | 22 |
| 第2遺跡 | 420 | 31 |
| 第3遺跡 | 600 | 40 |

| 階層 | 第一形態の遠距離攻撃 | 第二形態で追加 |
| --- | --- | --- |
| 第1遺跡 | 扇状弾・全周弾 | 魔槍 |
| 第2遺跡 | 扇状弾・全周弾・魔槍 | 衝撃波 |
| 第3遺跡 | 扇状弾・全周弾・魔槍・衝撃波 | 螺旋弾 |

## 画像・効果音・表示

- 主人公と通常敵には、待機・歩行・攻撃の4方向アニメーションがあります。
- 床・壁はタイル画像、ボスは透過PNGを使用します。
- HP・シールド・回避の再使用時間・遺物・真相度・発生中のイベント・ミニマップを表示します。濃霧中はミニマップ情報が遮断されます。
- 主人公の空振り音・命中音と、ボスの技ごとの発動音があります。ボスの音には低音の衝撃、金属音、短い残響を重ねています。
- 効果音は非同期再生です。同時再生は1音で、新しい音が前の音を置き換えます。
- 描画部品の再利用と待ち時間の調整で描画負荷を軽減しています。命中時の停止演出中も移動・回避を反映します。

## 動作確認

```powershell
python .\tools\validate_sprites.py
python .\src\dark_ruins_rpg.py --smoke-test
```

素材検証は主人公・通常敵の枚数や寸法、画像の透明部分、床・壁、Pythonソースの文字コードなどを調べます。ボス画像と音声はこの検証の対象外です。

`--smoke-test`は画面部品をダミーに置き換える簡易チェックです。実際のPNG読み込み・画面表示・スピーカーからの出音は確認しないため、素材変更後は通常起動でも確認してください。

効果音を作り直す場合は次を実行します。既存のWAVファイルが更新されます。

```powershell
python .\tools\generate_combat_sounds.py
```

## 起動できない場合

`No Python at ...`は、仮想環境が存在しないPythonの場所を参照しているときに発生します。Pythonをインストールするか、利用するPythonから仮想環境を作り直してください。VS Codeで選択しているPythonも確認してください。

`Can't find a usable init.tcl`が出る場合は、使用しているPythonのTcl/Tk環境を確認してください。Pythonを自分でインストールする場合は、Tcl/Tkを含めてインストールする必要があります。
