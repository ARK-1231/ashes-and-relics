# 灰の王国と記憶の遺物

Python標準のTkinterで動く、見下ろし型2Dダーク幻想RPGです。遺跡を探索して遺物と仲間を集め、ボス「王国の守護者」を倒します。外部ゲームライブラリは不要です。

## 起動方法

コマンドは、このREADMEがあるプロジェクトのフォルダーで実行してください。

### 同梱のPythonを使う場合（Windows）

```powershell
.\.python313\python.exe .\src\dark_ruins_rpg.py
```

同梱のPython 3.13で動作確認しています。VS Codeでは、`Ctrl + Shift + P` → `Python: Select Interpreter`から、プロジェクト内の`.python313\python.exe`を選択してください。

### 自分のPythonを使う場合

Python 3.10以降とTcl/Tkが必要です。Tkinterが使える環境で実行してください。

```powershell
python .\src\dark_ruins_rpg.py
```

追加パッケージのインストールは不要です。`requirements.txt`にも外部依存はありません。効果音はWindowsの`winsound`を使用し、対応しない環境では無音になります。

## ゲームの流れ

1. タイトル画面で「ゲーム開始」を選び、ランダム生成された遺跡を探索します。
2. 遺物に近づくと自動で入手できます。「灯火の小瓶」で封印扉を開きます。
3. 仲間と合流し、祠での回復や隠し碑文の調査をしながらボスへ進みます。ボス戦中は部屋の入口が封鎖されます。
4. 第1・第2遺跡のボスを倒すと、約1秒後に進行状況を引き継いで次の遺跡へ進みます。第3遺跡のボスを倒すとクリアです。

遺物・仲間・碑文で集めた真相度によって、通常エンド・断片エンド・真相エンドに分岐します。

## 操作

| キー・マウス | 操作 |
| --- | --- |
| `WASD` / 矢印キー | 移動 |
| マウス移動 | 攻撃方向を指定 |
| 左クリック | マウス方向へ攻撃 |
| `F` / `Enter` | 現在向いている方向へ攻撃 |
| `Space` | カーソル方向へ回避。約0.26秒間無敵、再使用まで10秒 |
| `E` | 近くの祠で回復／碑文を調べる |
| `1`～`9` | 入手済みの遺物スキルへ切り替え |
| `P` / `Esc` | ポーズ |
| `R` | ゲームオーバー／クリア後、同じ生成配置で再挑戦。再挑戦は1回まで |
| `N` | ゲームオーバー／クリア後、新しい冒険を開始 |

メニューでは`↑↓` / `W S`で選択、`Enter` / `Space`で決定します。マウスでも選択できます。

## 仲間と敵

- 仲間は第1遺跡のミラ、第2遺跡の灰騎士レオン、第3遺跡の星詠みノアの3人です。自動で追従・支援攻撃を行い、ミラは主人公のHP低下時に回復も行います。
- 仲間は240px以内で壁に遮られていないとき、初期耐久値20、仲間が1人増えるごとに15増加するシールド（1人で20、2人で35、3人で50）を自動付与します。HUDのゲージ上限も人数に連動します。加入時に残っているシールドはそのままで、次回付与から増加した耐久値になります。再付与間隔は全員共通で8秒、重ねがけはせず、ミラの回復を優先します。シールドは防御計算後のダメージをHPより先に吸収し、残量をHUDと水色のバリアで表示します。階層移動・再挑戦時にはリセットされます。
- 通常敵は灰の兵士・廃騎士・さまよう影の3種類です。
- ボス「王国の守護者」は遺跡ごとに強さと技が変わります。HPが半分以下になると第二形態へ移行し、HPとシールドが全回復します。

### ボスの攻撃と画像

| 攻撃 | ポーズ・色 |
| --- | --- |
| 近接斬撃 | 大剣を振る赤い斬撃 |
| 扇状弾 | 紫の魔法弾を放つ構え |
| 全周弾 | 桃色の魔法の輪を展開 |
| 魔槍 | 水色の魔槍を突き出す構え |
| 螺旋弾 | オレンジ色の螺旋をまとった構え |
| 衝撃波 | 剣を地面へ打ち込む金色の衝撃 |

溜め中と発動直後に対応する画像へ切り替わります。攻撃画像は各技1枚、歩行は正面向きの4コマアニメーションです。移動中だけ歩行コマを進め、停止時は待機、攻撃時は攻撃ポーズを優先します。

ボスの技は階層が上がるごとに増え、前の階層で使った技も引き継ぎます。近接斬撃は全階層・両形態で使用します。

ボスのHPは階層ごとに180、基本攻撃力は9ずつ増加します。遠距離攻撃のダメージも、この基本攻撃力をもとに技ごとの補正を適用して増加します。

| 階層 | 最大HP | 基本攻撃力 |
| --- | --- | --- |
| 第1遺跡 | 240 | 22 |
| 第2遺跡 | 420 | 31 |
| 第3遺跡 | 600 | 40 |

| 階層 | 第一形態の遠距離攻撃 | 第二形態で追加 |
| --- | --- | --- |
| 第1遺跡 | 扇状弾・全周弾 | 魔槍 |
| 第2遺跡 | 扇状弾・全周弾・魔槍 | 衝撃波 |
| 第3遺跡 | 扇状弾・全周弾・魔槍・衝撃波 | 螺旋弾 |

## 画像・効果音・表示

- 主人公と通常敵には、待機・歩行・攻撃の4方向アニメーションがあります。
- 床・壁はタイル画像、ボスは透過PNGを使用します。
- HP・シールド・回避の再使用時間・遺物・真相度・ミニマップを表示します。
- 主人公の空振り音・命中音と、ボスの技ごとの発動音があります。ボスの音には低音の衝撃、金属音、短い残響を重ねています。
- 効果音は非同期再生です。同時再生は1音で、新しい音が前の音を置き換えます。
- 描画部品の再利用と待ち時間の調整で描画負荷を軽減しています。命中時の停止演出中も移動・回避を反映します。

## 動作確認

```powershell
.\.python313\python.exe .\tools\validate_sprites.py
.\.python313\python.exe .\src\dark_ruins_rpg.py --smoke-test
```

素材検証は主人公・通常敵の枚数や寸法、画像の透明部分、床・壁、Pythonソースの文字コードなどを調べます。ボス画像と音声はこの検証の対象外です。

`--smoke-test`は画面部品をダミーに置き換える簡易チェックです。実際のPNG読み込み・画面表示・スピーカーからの出音は確認しないため、素材変更後は通常起動でも確認してください。

効果音を作り直す場合は次を実行します。既存のWAVファイルが更新されます。

```powershell
.\.python313\python.exe .\tools\generate_combat_sounds.py
```

## 起動できない場合

`No Python at ...`は、仮想環境が存在しないPythonの場所を参照しているときに発生します。同梱の`.python313\python.exe`を直接指定するか、利用するPythonから仮想環境を作り直してください。VS Codeで選択しているPythonも確認してください。

`Can't find a usable init.tcl`が出る場合は、使用しているPythonのTcl/Tk環境を確認してください。Pythonを自分でインストールする場合は、Tcl/Tkを含めてインストールする必要があります。
